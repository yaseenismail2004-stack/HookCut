# Clip Selection Scoring Rubric

## Hook: 0-100

- Immediate clarity: 0-15
- Curiosity: 0-20
- Emotional strength: 0-15
- Specificity: 0-10
- Audience relevance: 0-15
- Scroll-stopping strength: 0-15
- Opening pacing: 0-10

## Estimated Viral Potential: 0-100

- Hook strength: 0-20
- Predicted retention: 0-20
- Standalone clarity: 0-12
- Usefulness or entertainment: 0-12
- Emotional impact: 0-10
- Share potential: 0-8
- Save potential: 0-5
- Comment potential: 0-5
- Loop/replay potential: 0-5
- Visual suitability: 0-3

Scores are estimates, not guarantees. Lower confidence when transcript, visual, audio, or context evidence is incomplete. Apply the strict-diversity default before final ranking.
